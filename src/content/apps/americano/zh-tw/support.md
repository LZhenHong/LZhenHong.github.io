# Americano 技術支援

Americano 是一款 macOS 選單列應用程式,讓 Mac 保持喚醒——下載、簡報或任何長時間執行的作業都很實用。

## 聯絡方式

- 電子郵件:[leeden.dev@gmail.com](mailto:leeden.dev@gmail.com)
- GitHub Issues:[LZhenHong/Americano](https://github.com/LZhenHong/Americano/issues)

回報問題時請附上:macOS 版本、Americano 版本(選單 → 設定 → 關於),以及安裝管道(Mac App Store、GitHub 或 Homebrew)。

## 常見問題

**問:左鍵和右鍵有什麼不同?**
答:右鍵點按咖啡杯圖示可切換防睡眠開關;左鍵打開選單,可選擇時長或打開設定(⌘,)。

**問:選單列圖示的狀態顯示不正確?**
答:如果你使用 Bartender、Ice 等選單列管理工具並隱藏了 Americano 圖示,狀態顯示可能不準確。取消隱藏即可看到實際狀態。

**問:Mac App Store 版和 GitHub/Homebrew 版有什麼不同?**
答:同一個應用程式、同一個 bundle id——同一時間只能安裝一份,設定互通。GitHub/Homebrew 版透過 Sparkle 自動更新;Mac App Store 版透過 App Store 更新,並執行於 App Sandbox 中。

**問:如何再次檢視新手導覽?**
答:打開 設定 → 關於,選擇重新開啟導覽。
