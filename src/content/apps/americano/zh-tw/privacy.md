# 隱私權政策

生效日期：2026-08-20

## 概觀

本隱私權政策適用於 Americano（下稱「本應用程式」），一款由 YuQing Jiang 開發的 macOS 選單列工具。本政策說明本應用程式蒐集哪些資訊、如何使用，以及你有哪些選擇。

## 本應用程式蒐集的資訊

**Americano 不蒐集、儲存或傳輸任何個人資訊。** 沒有帳號、沒有統計分析、沒有廣告，也沒有任何形式的追蹤。

## 儲存在你裝置上的資料

你的設定——時長、電量閾值及其他偏好——儲存在 macOS 本機的使用者預設值中，絕不會離開你的 Mac。刪除應用程式即移除本體；設定仍保留於 macOS 使用者預設值中，如需一併清除，可在「終端機」執行 `defaults delete io.lzhlovesjyq.Americano`。

## 網路存取

- **Mac App Store 版：** 執行於 App Sandbox 且無網路權限——完全無法發起網路連線。
- **直接下載版（GitHub / Homebrew）：** 會透過 Sparkle 框架定期檢查託管於 GitHub 的更新來源。該請求不攜帶任何個人資訊；為判斷更新相容性，可能包含 macOS 版本等基本非識別資訊，並受 [GitHub 隱私權政策](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)約束。

## 第三方服務

本應用程式未整合任何第三方統計、廣告或當機回報服務。透過 Mac App Store 下載應用程式受 [Apple 隱私權政策](https://www.apple.com/legal/privacy/tzh/)約束。

## 兒童隱私

本應用程式不以 13 歲以下兒童為對象，亦不蒐集任何人的個人資訊。

## 政策變更

本政策如有變更，更新版本將發佈於本頁面，並註明新的生效日期。
