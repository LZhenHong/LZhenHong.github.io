# Americano 技术支持

Americano 是一款 macOS 菜单栏应用,让 Mac 保持唤醒——下载、演示或任何长时间运行的任务都很管用。

## 联系方式

- 邮箱:[leeden.dev@gmail.com](mailto:leeden.dev@gmail.com)
- GitHub Issues:[LZhenHong/Americano](https://github.com/LZhenHong/Americano/issues)

反馈问题时请附上:macOS 版本、Americano 版本(菜单 → 设置 → 关于),以及安装渠道(Mac App Store、GitHub 或 Homebrew)。

## 常见问题

**问:左键和右键有什么区别?**
答:右键点击咖啡杯图标可切换防睡眠开关;左键打开菜单,可选择时长或打开设置(⌘,)。

**问:菜单栏图标状态显示不对?**
答:如果你使用 Bartender、Ice 等菜单栏管理工具并隐藏了 Americano 图标,状态显示可能不准确。取消隐藏即可看到真实状态。

**问:Mac App Store 版和 GitHub/Homebrew 版有什么区别?**
答:同一个应用、同一个 bundle id——同一时间只能安装一份,设置互通。GitHub/Homebrew 版通过 Sparkle 自动更新;Mac App Store 版通过 App Store 更新,并运行在 App Sandbox 中。

**问:如何再次查看新手引导?**
答:打开 设置 → 关于,选择重新打开引导。
